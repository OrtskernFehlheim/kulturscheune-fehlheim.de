Die Verwaltung speichert direkt in euer GitHub-Repository. Dafür braucht diese Seite einmalig einen Zugangsschlüssel (Token). Er bleibt nur in diesem Browser gespeichert.

So bekommst du einen Token
  1. Auf github.com rechts oben auf dein Profilbild → Settings → ganz unten Developer settings.
  2. Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name z. B. „Raumbelegung“, Ablauf z. B. 1 Jahr.
  4. Bei Repository access: Only select repositories und euer Website-Repository wählen, für Notizen zusätzlich das private Repository.
  5. Bei Permissions → Contents auf Read and write stellen.
  6. Generate token klicken und den Token hier einfügen.
